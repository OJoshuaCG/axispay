Get paid with a link. We handle the rest.

Enter an amount, a currency and a concept. AxisPay creates a link with your brand on your own domain, you send it to your customer, and they pay by card from their phone. Stripe processes the charge; you never touch payment code.

From zero to your first payment in three steps

No payment code in your systems: AxisPay owns the link, the checkout and the Stripe side.

1

Connect Stripe

Platform onboarding, OAuth or a restricted API key. Pick the method that fits each tenant.

2

Create the link

A tenant system calls the public API with its key. Idempotency keys make retries safe.

3

Share it and get paid

The payer checks out on a hosted page. Tenants follow every payment in their own panel.

For your store or your ERP

An API that does not depend on the gateway

Create links from your system and receive signed events. Optionally, AxisPay asks your system whether the order is still valid right before the charge.

Read the documentation
POST /v1/payment_linkstest
curl https://api.<domain>/v1/payment_links \
  -H "Authorization: Bearer axp_test_••••" \
  -H "Idempotency-Key: order-1042" \
  -d amount="1250.00" \
  -d currency=MXN \

Built for real money from day one

Your domain, your brand

Payers see your name, logo and colors. AxisPay only signs at the bottom.

Money done right

Amounts are stored as integers in minor units, never as floats, so totals always add up.

Test and live, separated

Keys, data and webhooks are distinct. You cannot charge for real by mistake.

Signed events

Every outgoing webhook carries a verifiable signature so your system can trust it.

Isolated tenants

Every tenant is walled off from the others, with an isolation test on every endpoint.

Teams with roles and 2FA

Each person signs in with their own account, role and two-factor authentication. An audit log records it all.

Built for platforms with many customers

One installation, many isolated tenants, each with their own users, roles and payments.

Multi-tenant by design

Users, roles, two-factor authentication and an audit log come built in for every tenant.

Payment links API

A public API with API keys and idempotency, so your systems never touch card data.

Hosted checkout

Payers pay on a page served from your own domain, in English or Spanish, light or dark.

Outgoing webhooksIn progress

One endpoint per tenant with event selection and pre-payment validation.

Currency conversionIn progress

Quotes with a fixed tenant rate or the Banxico FIX rate, confirmed by the payer.
