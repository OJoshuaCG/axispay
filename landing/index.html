From request to payment in three steps

No payment code in your systems: AxisPay owns the link, the checkout and the Stripe side.

01

Request a link

A tenant system calls the public API with its API key. Idempotency keys make retries safe.

02

The payer checks out

A hosted checkout on your own domain, built on the Stripe Payment Element.

03

Everyone stays informed

Tenants follow their payments in their panel, and you can connect webhooks to react to events.

Built for platforms with many customers

One installation, many isolated tenants, each with their own users, roles and payments.

Multi-tenant by design

Every tenant is isolated. Users, roles, two-factor authentication and an audit log come built in.

Payment links API

A public API with API keys and idempotency, so your systems never touch card data.

Hosted checkout

Payers pay on a page served from your own domain, in English or Spanish, light or dark.

Money done right

Amounts are stored as integers in minor units, never as floats, so totals always add up.

Outgoing webhooksIn progress

One endpoint per tenant with event selection and pre-payment validation.

Currency conversionIn progress

Quotes with a fixed tenant rate or the Banxico FIX rate, confirmed by the payer.
